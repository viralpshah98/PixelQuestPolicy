2. Device Permissions

Pixel Quest requests specific system permissions to enable app blocking. These permissions are entirely optional — the quest and reward system works without them.

Android — Accessibility Service

Pixel Quest uses an Accessibility Service to detect when a blocked app is opened and display a focus gate screen. The service does not read, collect, or transmit any screen content, keystrokes, messages, or personal information. It only identifies the foreground app's package name to enforce your chosen blocking rules.

You can revoke this permission at any time from Settings → Accessibility.

iOS — Screen Time API

On iOS, Pixel Quest uses the Screen Time Family Controls framework to shield selected apps. Apple processes app selection on-device, and Pixel Quest has no ability to access app content or usage statistics beyond what you explicitly configure.

You can revoke this at any time from Settings → Screen Time.

4. SOS Access

The SOS feature grants you immediate, unrestricted access to a blocked app with no timer and no minute cost. When you trigger SOS:

  • The event is recorded locally in your activity history.
  • Blocking for that specific app is paused until you manually restore it.
  • No data about the SOS event leaves your device.

5. Data Retention & Deletion

All data persists on your device until you take one of these actions:

  • Clear app data — Removes all stored preferences and resets the app.
  • Uninstall Pixel Quest — All locally stored data is deleted by the operating system.

Since no data is stored externally, there is nothing to request deletion of from any server.

6. Children's Privacy

Pixel Quest does not knowingly collect personal information from children under 13. The app does not require any personal information to function — the nickname is optional, stored locally, and never transmitted.

7. Third-Party Services

Pixel Quest does not integrate with any third-party analytics, advertising, social media, or cloud services. The app operates entirely offline.
